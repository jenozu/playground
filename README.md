# Personal Coding Academy

A personal, browser-only, Codecademy-style learning platform: three-panel lessons, in-browser SQL/Python/JS execution, importable JSON+Markdown courses, and local progress. No backend, no accounts.

Status: early scaffold. The app shell, execution engines, course system and progress tracking are planned, not built. See `.taskmaster/` for the plan.

## Quick start
```
npm ci
npm run dev
```
See DEVELOPMENT.md for all scripts, ARCHITECTURE.md for the proposed design, COURSE-FORMAT.md for the course format (stub).
